# Getting help with TrenchHQ

Start with [setup and troubleshooting](docs/public/support.md), or **Help and FAQ**
inside the app. To run the current source, follow [Build and test](docs/BUILD.md).

## Choose the right place

| You want to… | Go to… |
| --- | --- |
| Ask how something works or get setup help | [Discussions: Q&A](https://github.com/gautamgpt1/TrenchHQ/discussions/categories/q-a) |
| Explore an idea | [Discussions: Ideas](https://github.com/gautamgpt1/TrenchHQ/discussions/categories/ideas) |
| Share your desktop layout | [Discussions: Show and tell](https://github.com/gautamgpt1/TrenchHQ/discussions/categories/show-and-tell) |
| Report a bug or request a specific feature/integration | [Issue forms](https://github.com/gautamgpt1/TrenchHQ/issues/new/choose) |
| Report a security vulnerability | [Private reporting instructions](SECURITY.md) |
| Report harassment or other unacceptable behavior | [Code of Conduct](CODE_OF_CONDUCT.md#enforcement) |

## Help us understand the problem

Include your app version or source commit, Windows version, the affected feature,
and the shortest steps that reproduce the problem. Describe what you expected
and what happened. For layout issues, include monitor count and display scaling.
For feed issues, name the exchange/chain/provider without sharing credentials.

If useful, select **Save diagnostics** in **Help and FAQ**. Review the JSON before
attaching it. Diagnostics are optional; do not upload settings folders, raw logs,
API keys, wallet secrets or browser profiles. Remove private information from
screenshots, including account details and personal wallet labels.

## Availability

Community support is provided as the maintainer and contributors are available.
There is no guaranteed response time. Provider billing, account access and
regional restrictions must be resolved with the service concerned.

TrenchHQ is available free through Microsoft Store. Use the official
[Windows installer](https://get.microsoft.com/installer/download/9PLRS95WJKSS?referrer=appbadge),
the [Store listing](https://apps.microsoft.com/detail/9PLRS95WJKSS), or install with
`winget install --id 9PLRS95WJKSS --source msstore`.
Developers can [build from source](docs/BUILD.md).
