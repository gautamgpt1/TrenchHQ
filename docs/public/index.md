# Your crypto HQ, always in view.

TrenchHQ is a customizable crypto desktop companion for Windows. Keep prices,
wallet activity, X feeds, websites and other apps visible in floating overlays
or panels along your screen edges. Arrange them across your monitors and save
a layout that fits the way you work.

<p><a class="download-button" href="https://get.microsoft.com/installer/download/9PLRS95WJKSS?referrer=appbadge">Download for Windows</a></p>

Free for Windows x64. Run **TrenchHQ Installer.exe** to install through Microsoft
Store, with trusted signing and automatic updates.
[View in Microsoft Store](https://apps.microsoft.com/detail/9PLRS95WJKSS).

## Make it your own

- Watch exchange prices or specific on-chain pools with **Price Ticker**.
- Follow public addresses with **Wallet Watcher**.
- Keep selected accounts in view with **X Tracker**.
- Add a **Website**, or pin a compatible **Application Window**.
- Choose each panel's monitor, position, size and appearance.

## Get started

Use **Download for Windows** above, or install with WinGet:

```powershell
winget install --id 9PLRS95WJKSS --source msstore
```

See [release notes](https://github.com/gautamgpt1/TrenchHQ/releases),
[build from source](https://github.com/gautamgpt1/TrenchHQ/blob/main/docs/BUILD.md),

## Your data

TrenchHQ runs on your desktop and connects directly to the services you use.
There is no TrenchHQ account. Read the [privacy policy](privacy.txt) for credentials,
website sessions, network requests and deleting local data.

[Release and code signing policy](https://github.com/gautamgpt1/TrenchHQ/blob/main/docs/RELEASE.md#code-signing-policy)
